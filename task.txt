Case Study: Inventory Management Dashboard Implementation 
Background & Context: Welcome to the Engineering Team. You have just been hired 
as a Full Stack Developer. You are tasked with building internal tools for our Operations 
Department, which handles merchandise distribution. Currently, the team tracks 
inventory manually, which causes delays and data discrepancies. The goal of this 
project is to digitize our inventory tracking to provide real-time visibility into stock levels. 
The Problem: While our product line is growing, our tracking methods remain archaic. 
The warehouse team cannot easily view current stock levels, leading to potential 
stockouts or overordering. We need a lightweight, web-based solution that connects 
directly to our database to show the current status of items like T-shirts, jeans, and 
sneakers. We are not looking for a complex ERP system yet, but rather a "Minimum 
Viable Product" (MVP) dashboard that proves we can display live data from the 
backend. 
The Task & Deliverables: Develop a functional web dashboard that connects to a 
Supabase (PostgreSQL) backend and displays product inventory. 
Please provide your submission as a GitHub Repository link (and a hosted demo link if 
possible) that includes: 
1. Technical Implementation: 
○ Backend: Set up a Supabase project using the provided SQL schema. 
○ Frontend: Build the user interface using Plain HTML, CSS, and Vanilla 
JavaScript (or your preferred framework). 
○ Integration: Ensure the frontend successfully fetches and displays the 
product name, stock count, and last updated timestamp from the 
database. 
2. Documentation (README.md): 
○ A brief explanation of your code structure. 
○ Instructions on how to run the project locally. 
○ If you used AI tools, briefly mention how they assisted your workflow.
